## 01 · 核心方法论

直接让 AI 从零做网站效果差、不个性化。最佳流程：

1. **找好看的网站**（从下方灵感库挑参考对象）
2. **让 AI 抓代码 / 截图 / 风格关键词**（配色 hex、字体、间距、动效参数）
3. **整合制作**（把抓到的风格 DNA 喂给 AI 再让它写，而不是凭空生成）

对 yjyblog.xyz 的用法：改版前先在同主题优秀博客/landing 站找 2-3 个参考，
提取风格关键词和配色，再让 AI 基于此改 Hugo 模板。

## 对 yjyblog.xyz 的落地建议

当前博客是 Hugo + 原生 CSS（无 React），02/08/09 里的 React 组件库和 AI 生成工具**不能直接引入**，但以下可零成本使用：

- **04 灵感库**：改版前先在 SiteInspire / Minimal Gallery 找 2-3 个同调性博客参考
- **07 素材**：Hero Patterns（背景纹理）、Lucide（SVG 图标可直接内联进模板）、unDraw（文章配图，可调成品牌色）、Realtime Colors（整站配色预览）
- **03 动效**：纯 CSS 不够时用 anime.js（单文件、无构建）
- **06 Codrops**：抄纯 CSS 微交互的最佳来源
